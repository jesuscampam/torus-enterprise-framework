# utils/

Utilidades genéricas de frontend sin estado ni dependencia de React.

## Responsabilidad

- Funciones puras de formateo (fechas, números, texto), validación genérica y transformación de datos.
- Helpers reutilizables por `components/`, `pages/`, `hooks/` y `services/`.

## Qué NO debe contener

- Hooks de React (pertenecen a `hooks/`).
- Lógica de negocio específica de una aplicación.
